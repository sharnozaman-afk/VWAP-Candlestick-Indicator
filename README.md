# VWAP-Candlestick-Indicator
# Project Overview 
I am developing a simple VWAP (volume-weighted average price) calculator in Python using simulated trade prices and volumes. The calculator multiplies each price by its corresponding trading volume, adds those values together, and divides by the total volume to calculate VWAP. Using sample numbers allows me to explore how trades with different volumes influence the resulting average. The project is an introductory learning exercise that helps me practice Python and better understand the calculation behind an execution benchmark, without connecting to a live market data feed.
